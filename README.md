# javascript-racingcar-precourse

## 구현목록 (자동차 경주)

### ✅ 기능 구현
- [ ] 사용자 입력
    - [ ] 사용자의 자동차 이름 입력(쉼표 기준)
- [ ] 입력 구분
    - [ ] 쉼표 기준으로 각각 이름 구분
- [ ] 게임
    - [ ] 사용자의 이동 횟수 입력
    - [ ] 각각 입력된 이동 횟수만큼 진행
    - [ ] 무작위 값이 4 이상일 경우 전진, 4 미만일 경우 유지
    - [ ] 가장 많이 전진한 자동차 이름을 우승자로 출력하며 중복일 경우 쉼표 기준으로 중복 출력

### ❌ 에러 확인
- [ ] 사용자 이름이 5자 이하가 아닌 경우 에러
- [ ] 전체 전진 횟수가 0인 경우 확인
