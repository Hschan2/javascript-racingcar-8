# javascript-racingcar-precourse

## 구현목록 (자동차 경주)

### ✅ 기능 구현

- [x] 사용자 입력
  - [x] 사용자의 자동차 이름 입력(쉼표 기준)
- [x] 입력 구분
  - [x] 쉼표 기준으로 각각 이름 구분
- [x] 게임
  - [x] 사용자의 이동 횟수 입력
  - [x] 각각 입력된 이동 횟수만큼 진행
  - [x] 무작위 값이 4 이상일 경우 전진, 4 미만일 경우 유지
  - [x] 가장 많이 전진한 자동차 이름을 우승자로 출력하며 중복일 경우 쉼표 기준으로 중복 출력

### ❌ 에러 확인

- [x] 사용자 이름을 입력하지 않거나, 쉼표만 있는 경우
- [x] 사용자 이름이 5자 이하가 아닌 경우 에러
- [x] 사용자가 시도할 횟수를 입력하지 않거나 0을 입력한 경우

### ♻️ 리팩토링

- [ ] 들여쓰기 뎁스가 3 이상인 함수를 찾아 2까지 줄이기
- [ ] 함수가 한 가지 일만 하도록 수정하기
